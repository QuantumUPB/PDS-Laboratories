# Final task: transfer a file between containers

The specification and verification commands are in `docs/lab-02.md`.

Create `compose.yaml` and `.env.example` in this directory. Copy
`.env.example` to `.env` for local configuration. Write one Python script
and one Dockerfile in each service directory: `sender/` and `receiver/`.
Keep `input/` outside both build contexts. The supplied `sample.txt` is test
data. The Python scripts and Compose configuration are student work.
